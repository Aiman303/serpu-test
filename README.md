# Serpuru — сайт

Урезанная часть приложения Серпу: поиск лекарства, скан упаковки, справка Серпу, самочувствие, «Моя аптечка», вход и «Скачать».
Сайт без сборки: обычные HTML, CSS и JS. Открывается с любого статического хостинга.

## Что где лежит

```
site/                 ← это и выкладываем
  index.html          все экраны (переключаются по #адресу)
  css/app.css         стили, светлая и тёмная тема
  js/config.js        адрес Supabase и publishable key (публичные, их можно держать в коде)
  js/app.js           поиск, карточка, скан, ИИ, вход, аптечка
  js/rig.js           живой Серпу: риг + поведение (прыжки, сердечки, вечеринка, головокружение, сон)
  js/fx.js            живой фон с таблетками и мини-Серпу в шапке и подвале
  data/drugs.json     7 487 лекарств из реестра Минздрава КР (без медизделий и повторов)
  data/shelves.json   витрины на главной
  img/d/              2 561 фото упаковок (webp, ~10 КБ)
  img/serpu/          Серпу: стикеры, логотип, og-картинка, Serpu.png для кнопки «Скачать»
  sounds/             звуки Серпу
  404.html, robots.txt, _headers
supabase/
  functions/serpu-ai/index.ts       ИИ-функция (уже задеплоена)
  migrations/…_serpuru_init.sql     таблицы (уже применены)
_build/ (на рабочем столе)          скрипты, которые собрали data/ и img/d/ из папки реестра
```

## Что уже сделано в Supabase (проект Serpuru)

- Таблицы `profiles`, `user_meds` (аптечка, RLS: каждый видит только своё), `ai_usage` (суточные лимиты), `ai_cache` (кэш ответов).
- Функция `serpu-ai` задеплоена, `verify_jwt = false` — сайт ходит с publishable key, пользователь определяется по своему токену.

## Что осталось сделать вам

1. **Ключи Gemini.** Supabase → Edge Functions → Secrets → добавить:
   - `GEMINI_API_KEY` — первый ключ;
   - `GEMINI_API_KEY_2` — второй (запасной: функция переключится на него при лимите).
   Без ключей ИИ отвечает «Серпу сейчас не может ответить». Ключи не кладите в код сайта.
2. **Вход по почте с кодом.** Authentication → Email Templates → Magic Link: добавить в письмо строку `Код: {{ .Token }}`.
   Встроенная почта Supabase отправляет мало писем в час — для запуска подключите свой SMTP (Authentication → SMTP).
3. **Адреса.** Authentication → URL Configuration: Site URL = адрес сайта, в Redirect URLs добавить его же.
4. **Google.** Authentication → Providers → Google: Client ID и Secret из Google Cloud.
5. **Telegram.** Authentication → Providers → Custom → OIDC с идентификатором `custom:telegram`
   (issuer `https://oauth.telegram.org`, Client ID/Secret из @BotFather → Login Widget). Если назовёте иначе — поменяйте `telegramProvider` в `js/config.js`.

## Как выложить

Любой статический хостинг. Например, Cloudflare Pages:

```
npx wrangler pages deploy site --project-name serpuru
```

## Запуск у себя

```
npm install      # один раз
npm run dev      # откроет http://localhost:5173 и перезагружает страницу при правках
```

Важно: сайт лежит в папке `site/`. Если запускать `python3 -m http.server` из домашней папки, браузер покажет
список файлов (Directory listing) вместо сайта — `npm run dev` сам открывает нужную папку.

## Данные

`npm run data` пересобирает `site/data/drugs.json` и `shelves.json` из `_build/drugs.json` (скрипт `_build/fix_data.py`):
- убирает фото, привязанные в реестре не к тому препарату (другое название, форма, страна или завод);
- склеивает повторы (одно название + один производитель);
- снимает штрихкод с чужих препаратов, если у кода есть «хозяин» (фото с этим кодом);
- сохраняет полные списки для разделов каталога.

## Оформление

Кнопка с луной в шапке: светлая/тёмная, с таблетками на фоне или без. По умолчанию — светлая с таблетками.

## Настройки ИИ (кратко)

Режимы: `scan` (фото → название), `ask` (вопрос про препарат), `symptoms` (самочувствие).
Жёсткие правила в функции: без диагнозов, без доз (фразы с дозами вырезаются фильтром), без рецептурных препаратов в советах,
красные флаги → 103/112, по симптомам максимум 2 самых безопасных безрецептурных вещества и только для типичных лёгких случаев у взрослых,
в конце всегда «Подобрать лечение по симптомам может только квалифицированный врач или фармацевт».
Скорость: функция просит у Gemini минимум «размышлений» и страхует запросы — если модель молчит 6 секунд
или отвечает ошибкой, параллельно идёт запрос к запасной модели/ключу. Скан и вопросы сначала идут в быструю
lite-модель, самочувствие — в основную. Для проверки скорости можно добавить в запрос `"debug": true` — в ответе
появится `trace` (какая модель сколько отвечала, без ключей).
Лимиты в сутки (гость / вошедший): скан 15/40, вопросы 30/80, самочувствие 12/30 — меняются в `LIMITS` в функции.
