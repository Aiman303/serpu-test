## 1. Что за продукт

**Серпу** — экосистема о лекарствах для Кыргызстана с маскотом **Серпу** (фиолетовый змей,
живой, с эмоциями, в духе Duolingo).

Главная идея (очень важно для любых решений):
**Серпу — продукт ОТ ВРАЧЕЙ для пациентов.** Не родственники следят за больным, а врач:
врач назначает лечение и видит, принимает ли пациент лекарства; пациент получает напоминания,
живого Серпу и чат с врачом.

Две части:

| Часть | Где лежит | Технологии | Статус |
|---|---|---|---|
| **Сайт** (справочник лекарств) | `~/Рабочий стол/Serpuru/site/` | чистый HTML/CSS/JS, без сборки; Vite только как dev-сервер | в продакшене на Cloudflare Pages |
| **Android-приложение** (врач ↔ пациент) | `~/dev/serpu_app/` (симлинк `~/Рабочий стол/Serpuru/app`) | Flutter 3.47.9 / Dart 3.13 | работает в эмуляторе, APK ещё не публиковался |
| **Бэкенд** (общий) | Supabase, проект `jjxtvixlwpwwcznnzkes` | Postgres + RLS, Realtime, Edge Functions (Deno) | продакшен |

## 4. Сайт (`site/`)

Одностраничник на хеш-роутинге. Экраны — `<div class="view" data-view="...">` в `index.html`.

| Хеш | Экран |

| `#ask` | «Самочувствие» (симптомы → ИИ) |
| `#apteki`, `#apteki-<i>` | **карта аптек Бишкека** (Leaflet + OSM, маршрут 2ГИС/Google/Яндекс, «Рядом со мной», проверка наличия на apteki.kg) |
| `#me` | «Моя аптечка» (localStorage или Supabase `user_meds` при входе) |
| `#login`, `#privacy`, `#terms` | вход (Google/Telegram/почта), юр. страницы |

Файлы:
- `js/app.js` — вся логика: поиск (транслит, триграммы), карточка, скан, ИИ, аптечка, вход, роутер (`show()`, `route()` в конце файла), раздел аптек (`renderPharm`, `aptekiUrl`, `routeUrl`).
- `js/rig.js` — риг маскота (`window.Serpu.trigger(name)`: tap, love, party, dizzy, pet, pill, streak, record, remind, missed, sad, think, found, warn, freeze, talk, surprised, sleep, wake; `say(text)`).
- `js/fx.js` — фон с плавающими таблетками, мини-Серпу.
- `js/config.js` — Supabase URL и publishable key (публичный, это нормально).
- `data/drugs.json` (реестр), `data/shelves.json` (категории), `data/pharmacies.json` (332 аптеки из OpenStreetMap: `n` имя, `lat`, `lon`, `a` адрес, `h` часы, `p` телефон).

Режимы оформления: `html[data-theme="light|dark"]` × `html[data-fx="on|off"]` (таблетки на фоне) = 4 темы;
`html[data-a11y="on"]` — версия для слабовидящих (zoom 1.25, контраст). Цвета — только через CSS-переменные в `:root`.

Внешние скрипты: Supabase JS (jsdelivr), Leaflet 1.9.4 (cdnjs, грузится лениво только на `#apteki`).
Тайлы карты — `tile.openstreetmap.org` (CARTO теперь требует ключ — не возвращай его).

Пакет `kg.serpuru.serpu`, название «Серпу». Шрифт Nunito, Material 3.

**Роли** (`Settings.role`): нет роли → `/welcome` (онбординг: «Я врач» / «Я пациент»).

Врач: `Пациенты /doctor` · `Мой QR /doctor/qr` · `Реестр /doctor/meds`; карточка пациента `/doctor/patient/:id` (вкладки «Лечение» с сеткой 7 дней и «Чат»).

## 6. Бэкенд Supabase (`jjxtvixlwpwwcznnzkes`) — ПРОДАКШЕН

Миграции (копии лежат в `supabase/migrations/`): `serpuru_init`, `serpu_care` (врач ↔ пациент), `serpu_care_links_realtime`.

Таблицы:
- `profiles` (+ `role`, `full_name`, `specialty`, `clinic`, `link_code` — 6 цифр у врача)
- `care_links` (врач ↔ пациент), `prescriptions` (`times text[]`, `start_date`, `end_date`, `active`, `note`, `doctor_id`)
- `dose_logs` (unique `prescription_id, due_at`; статус taken/missed/skipped), `messages` (чат по `link_id`)
- `user_meds` (аптечка сайта), служебные таблицы лимитов ИИ
RPC: `become_doctor(p_full_name, p_specialty, p_clinic)` → код; `link_doctor(p_code)` → json.
Хелперы RLS (security definer): `is_doctor_of`, `is_linked_with`, `is_link_party`. RLS включён везде.
Realtime: `messages`, `dose_logs`, `prescriptions`, `care_links`.

Edge Functions (`supabase/functions/`):
- `serpu-ai` (v9) — Gemini: `kind` = `ask` (вопрос о лекарстве), `scan` (фото упаковки), `symptoms`. Хеджированные запросы, быстрые модели первыми, лимиты по IP. Ключ Gemini — в секретах Supabase.
- `serpu-device` (verify_jwt=false) — создаёт «аккаунт устройства» (`d<hex>@device.serpuru.kg` + случайный пароль), 20/сутки/IP. Так приложение входит без пароля.

Тестовые данные в базе: врач «Асанова Айгуль Маратовна» (код **601370**), врач «Aig» (код 043441), пациенты «Bakyt», «Бакыт Асанов», «Гульмира Токтосунова». Не удаляй без разрешения пользователя.

## 9. Известные ограничения и долги

- Наличие лекарств по аптекам: открытого API в КР нет (apteki.kg, apteka24.kg, neman.kg). Сейчас — ссылка на поиск apteki.kg. Для встроенного наличия нужно партнёрство с apteki.kg.
- В `pharmacies.json` адреса есть только у 43 из 332 аптек (данные OSM).
- 6-значный код врача теоретически перебираем — для прототипа ок, перед запуском нужен лимит попыток в `link_doctor`.
- Вход в приложении — «аккаунт устройства» без восстановления; при переустановке данные пациента теряются.
- `Notify.scheduleCourses` планирует ежедневные будильники без учёта `end_date` курса.
- «Не забудь таблетки» смотрит только дозы сегодняшнего дня (выход около полуночи не учитывает завтрашние утренние).
- Тестов (`test/`) пока нет.
- Квота Gemini ограничена.
